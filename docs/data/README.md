# data/dashboard.json

Generated by `export-dashboard.py` (in the flip-suvs-for-profit goal workspace)
after every monitor run. Do not hand-edit — it is overwritten.

## Schema

```json
{
  "meta": {
    "updatedAt": "ISO-8601 UTC timestamp of export",
    "markets": ["madison", "detroit"],
    "radiusMiles": 150,
    "yearMin": 2017, "yearMax": 2024,
    "notes": "…"
  },
  "listings": [
    {
      "id": "Facebook Marketplace listing id",
      "market": "local | national",
      "metro": "madison | detroit | <national metro, e.g. chicago>",
      "model": "jeep-grand-cherokee | chevy-equinox",
      "modelLabel": "human-readable model",
      "title": "listing title",
      "year": 2020, "price": 16500.0,
      "mileage": 66000, "titleStatus": "clean | salvage | unknown",
      "location": "City, ST", "distanceMi": 97.0,
      "condition": "as reported by Marketplace",
      "outlier": false, "outlierReason": "",
      "seenAt": "ISO-8601 UTC of last sighting",
      "url": "https://www.facebook.com/marketplace/item/<id>"
    }
  ],
  "rollup": { "…daily Madison/Detroit medians…" },
  "nationalRollup": { "…weekly 15-metro medians…" }
}
```

## Notes

- `listings` is de-duplicated to the latest sighting per (market, listing id).
- `outlier: true` rows are flagged bait/placeholder prices; the page excludes
  them from medians but they remain in the file for audit.
- `titleStatus: "unknown"` means the seller did not declare a title status in
  the structured field — it is not evidence of a salvage title.
- The page fetches this file with `?t=<Date.now()>` and `cache: no-store`, so a
  fresh export is visible on the next page load after the push rebuilds.
